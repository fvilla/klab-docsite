# k.LAB documentation site

This repository assembles documentation maintained by the k.LAB projects into one Material for
MkDocs site. Source documentation remains authoritative in each sibling repository; the copies
under `docs/reference/` are generated by the synchronization script and should not be edited
directly. The manifest supports both documentation directories and individual supplemental files.

## Local setup

Python 3.9 or newer is required.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python scripts\sync_docs.py
mkdocs serve
```

The site is then available at `http://127.0.0.1:8000/`.

## Synchronizing source documentation

Sibling projects are configured in `doc-sources.toml`. Paths are resolved relative to this
repository, so the default setup assumes all projects remain siblings under the same `git/`
directory.

```powershell
# Synchronize all configured projects.
python scripts\sync_docs.py

# Verify that committed copies match their sources without changing files.
python scripts\sync_docs.py --check

# Synchronize one project only.
python scripts\sync_docs.py --project klab-services
```

The PowerShell wrapper `scripts/sync-docs.ps1` provides the same operation. Missing documentation
is an error for required projects and a reported skip for optional future projects.

## Building

```powershell
mkdocs build --strict
```

The generated site is written to `site/`. CI runs the same strict build for every change.

Run the synchronization tests with:

```powershell
python -m unittest discover -s tests
```
