# k.LAB documentation

This site brings together the architecture, service contracts, language implementation guides,
IDE documentation, and component references for the k.LAB software stack.

## Start here

- **Platform architecture** explains the service-oriented system and its shared lifecycle.
- **Services** documents resource management, semantic resolution, scopes, and expressions.
- **k.Actors** describes analysis and compilation of reactive behaviors.
- **IDE** covers the desktop application, its architecture, build, and major UI components.
- **Components** is the landing area for component-specific documentation as it becomes available.

!!! info "Source of truth"
    Most reference pages are synchronized from sibling repositories. Edit those pages in their
    originating project and run `python scripts/sync_docs.py`; do not edit generated copies under
    `docs/reference/`.
