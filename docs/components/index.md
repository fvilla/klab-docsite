# Component documentation

k.LAB components extend the platform with adapters, runtime functions, language services, and
domain-specific capabilities. Component documentation remains owned by each component repository
and is synchronized into this site when that repository provides a `docs/` directory.

The initial source manifest reserves ingestion paths for:

- `klab.component.generators`
- `klab.component.geospatial`

Additional sibling projects can be added to `doc-sources.toml` using the same convention.
